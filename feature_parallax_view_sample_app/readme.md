# Feature Parallax View Sample App

A minimal Android Jetpack Compose application showcasing the **Feature Parallax View** library in action. It demonstrates both the DSL-based and Modifier-based APIs.

---

## Prerequisites

- Android Studio Flamingo or newer
- Android SDK 24+

---

## Getting Started

1. **Open** this repository in Android Studio.
2. **Sync** the project when prompted.
3. **Run** the `MainActivity.kt` file on an emulator or device.
